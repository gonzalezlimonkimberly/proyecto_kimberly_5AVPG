Donaciones y suministros

Tu apoyo puede ayudar a mejorar la vida de muchos animales. En nuestro centro de acopio recibimos diferentes tipos de suministros que serán utilizados para brindarles alimentación, higiene, comodidad y cuidados.

¿Qué necesitamos?

Alimentos

  • Alimento seco para perros
  • Alimento seco para gatos
  • Alimento húmedo para perros
  • Alimento húmedo para gatos
  • Premios para mascotas

Cobijas y comodidad

  • Cobijas limpias
  • Toallas
  • Camas para mascotas
  • Tapetes
  • Transportadoras

Artículos de limpieza

  • Jabón para limpieza
  • Desinfectante
  • Cloro
  • Bolsas para basura
  • Trapos y esponjas

Otros artículos

  • Platos para alimento y agua
  • Correas
  • Collares
  • Juguetes para mascotas
  • Arena para gatos

Centro de acopio

Lugar: Escuela / Centro de acopio PAEC

Dirección: Área destinada para la recepción de donaciones.

Fecha: Del 5 al 16 de octubre de 2026

Horario: Lunes a viernes, de 8:00 a.m. a 2:00 p.m.

Recepción: Las donaciones pueden entregarse directamente en el centro de acopio durante el horario establecido.
